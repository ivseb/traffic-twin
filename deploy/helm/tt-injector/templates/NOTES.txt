Instrument a workload by annotating its POD TEMPLATE:

  spec:
    template:
      metadata:
        annotations:
          traffic-twin.io/inject: node        # {{ range $i, $l := (list "node" "python" "java" "dotnet" "go" "php") }}{{ if $i }} | {{ end }}{{ $l }}{{ end }}

In the namespace of the application create the Secrets (optional: without them the pod starts and the SDK is inert):
  kubectl -n <app-ns> create secret generic {{ .Values.enrollSecret }} --from-literal=url=https://<tt-core intake>:4318 --from-literal=token=tte_...
  kubectl -n <app-ns> create secret generic {{ .Values.hmacSecret }} --from-file=hmac-key=./hmac.key

The webhook is registered with failurePolicy {{ .Values.webhook.failurePolicy }}: if it is down, pods are created without the SDK.

WARNING: failurePolicy is not Ignore: an unavailable injector blocks the creation of annotated pods.
{{- end }}
